01 / 重点项目已上线 · 持续迭代

Resume Fit AI · Agent 求职助手

把简历、目标岗位和投递记录放在一起，核对表达与岗位要求，让每次修改都有原文证据可查。

怎么使用
导入简历 → 保存并选择版本 → 先做简历体检，或录入完整岗位 JD 对比 → 按需保存新版本并导出 PDF → 记录投递与面试进度。也可整理公司资料和待核实问题。

找岗位时先确认条件，再打开招聘平台搜索入口并保存完整 JD。自动职位搜索尚未启用，投递跟进由用户手动记录。

实现与验证

模型适配 AI 层、通用 Agent 层与求职业务应用层分开。ToolCatalog / ToolExecutor 注册工具并校验 JSON 参数、输出限制、白名单与简历版本归属；多轮调用按原调用 ID 返回结果。

限制轮数、工具次数、Token、总时长与单次超时；支持持久化任务、执行轨迹、取消与迟到结果隔离。

Agent 版本已在简历站上线，沿用真实模型配置。2026-10-30 更新统一界面、当前版本展示、可折叠引导及分析状态反馈，覆盖桌面和手机操作。

本轮发布前 79 项后端测试通过，3 项真实模型测试按设计跳过；上线后健康接口和 11 个页面、静态资源核对通过。此次发布验收未发起模型分析；公开仓库仍待同步本地较新的 Agent 实现。

02 / 重点项目本地 CLI / Web · 公开检索基线

RAG LangChain Lab

从自己的资料中查找有出处的答案，检查引用与证据是否足够；对复杂问题探索多步检索和调查。

怎么使用
在本地配置模型接口，导入有权使用的 TXT / Markdown 文档并建立索引，再用 CLI 或本地 Web 提问、查看原文与检索过程。目前暂无在线演示。
检索与 Agent 实现

以内容哈希与稳定 Chunk ID 增量索引，组合 Vector、精确词和 BM25，经 RRF 融合、Cross-Encoder 重排并补充相邻证据；保留引用，证据不足时拒答。

多步调查实践加入工具权限、步数、超时、Token / 成本预算与检查点恢复。公开仓库提供固定检索基线，Agent 扩展仍在整理同步。

评测记录与适用范围

原基线冻结集首次证据决策为 24/30。MultiHop-RAG 外部挑战样本含 609 篇文档、75 个可回答题：固定检索基线至少命中一条证据 72 题，全部证据命中 33 题。

第二领域 5 篇文档、22 题的本机受控评测中，候选从 18 缩到 6，检索 P50 降低约 24%，Recall@3、MRR 与证据决策不变；计时不含生成，含冷启动。

这些结果只描述特定语料、样本与运行环境，不代表通用回答准确率或生产性能保证。
